- (direction) Architect recommends paragraph-level cited answer blocks rather than one free-form message-level citation list: each factual paragraph/block carries SourceExcerpt ids, while refusals/errors may carry none or only redirection excerpts. - (decision) Answer contract uses paragraph/block-level source binding: Worker returns structured answer blocks, where each factual paragraph/block must carry SourceExcerpt ids from the same response; unsourced blocks are allowed only for transitions, limitations, refusals, or professional failure messages. SourceExcerpt records include stable response-local ids, source document path under content/public, excerpt text, and enough location metadata for diagnostics. Binds FR-7, FR-10, FR-11, FR-12, FR-14, FR-15, FR-21, FR-22; prevents vague whole-answer citation lists, post-hoc frontend citation invention, and unsupported factual paragraphs.
- (decision) Answer safety pipeline is gate-before-retrieve and validate-after-generate: Worker first applies deterministic limits/rules and, when needed, a small LLM scope classifier that sees only the current question plus minimal same-conversation context and no Knowledge Base content; only allowed professional/documented-scope questions proceed to retrieval over content/public-derived D1 FTS. After generation, Worker validates that factual blocks are sourced and prohibited/error/private content is absent; unsafe, unsupported, quota-exhausted, or classifier-failed paths fail closed with professional partial/refusal/failure output. Binds FR-11 through FR-15, FR-21, FR-22 and NFR abuse/security; prevents the answer LLM from being sole authority on whether a question may be answered and prevents Knowledge Base leakage into scope classification.
- (decision) V1 retrieval uses deterministic Markdown chunking plus D1 SQLite FTS over content/public-derived text and public metadata; no vector database or embeddings in V1. Markdown sources may include public titles/topics/aliases to improve lexical recall. Retrieval returns ranked chunks that become the only eligible Source Excerpt pool for answer generation; missing/weak retrieval produces partial/missing-evidence output. Vector/semantic retrieval is deferred until launch tests prove FTS insufficient. Binds FR-9, FR-10, FR-11, FR-21, FR-22 and simplicity/cost NFRs; prevents vector-DB complexity, opaque retrieval, and LLM citations outside retrieved public chunks.

- (decision) Retention model: D1 records use created_at as the retention source of truth rather than storing expires_at; retention duration is policy in application/job code so it can change without data migration. Deletion requests are retained indefinitely as non-sensitive operational metadata with status and timestamps, not as conversation content. Binds FR-16, FR-19, FR-20, FR-21, FR-22 and privacy/operations NFRs; prevents stale per-row expiry policy, manual-only retention compliance, and loss of deletion-request audit visibility.

Binds FR-19, FR-20, FR-21, FR-22; prevents ambiguous deletion-request lifecycle timestamps and avoids storing sensitive free-text request content.
