# Candidate Copilot — maquette

Cette archive contient la maquette statique de Candidate Copilot.

## Utilisation

Ouvrir simplement `index.html` dans un navigateur. Aucun serveur, installation ou compilation n'est nécessaire.

Le HTML, les styles CSS et le JavaScript sont actuellement regroupés dans ce fichier unique afin de faciliter les essais et le partage.

## Contenu fonctionnel

- mise en page responsive pour ordinateur et mobile ;
- questions suggérées cliquables ;
- champ de saisie libre ;
- réponses de démonstration ;
- liens de profil et emplacement réservé au CV.

## Limite de la maquette

Les réponses sont simulées côté navigateur. La base Markdown, le moteur de recherche, SQLite et le LLM ne sont pas encore connectés.
