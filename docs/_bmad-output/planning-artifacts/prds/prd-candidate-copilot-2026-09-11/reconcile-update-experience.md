## Retry distinction — no policy silently approved

- **Unknown-outcome same-submission recovery is settled:** reuse the original request identity, question and immutable Submitted Scope, regardless of newer composer edits. It must neither consume another logical turn nor duplicate the submission/display.
- **Received recorded-failure new-turn retry is intentionally unresolved:** FR-8 permits an explicit new logical turn with the same text only for a recoverable technical failure. PRD §10 question 5 assigns BC confirmation of its scope and presentation, preserving the prepared draft/Active Selection. Neither original-scope copying nor current-selection use is already approved. FR-21 requires resolution/testing before implementing that action; the addendum repeats this boundary.

This open decision is not a missing obligation or a reconciliation gap.
