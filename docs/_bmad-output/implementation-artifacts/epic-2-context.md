## Requirements & Constraints

- Completed amendments are documentation only: Story 2.0 is unexecuted, criteria not separately approved, taxonomy undecided. With BC, design workflow/agent, finite types/formats and genuine validated per-type pilots. BMad Workflow Builder is intended authoring aid, not installed/runtime dependency. Prove adaptive interviewing, corrected synthesis, fresh-session checkpoint resume, separate factual/outside-reader completeness checks and final-version pilots; required gaps block, synthetic probes cannot replace real pilots or invent achievements.
- Keep raw notes/drafts/pilots gitignored in `content/private` and reusable nonsensitive tooling outside both content trees. BC reviews inputs/attachments and consents before remote processing; disclose actual provider/session-log retention/deletion limits. Authoring neither inherits runtime retention nor auto-publishes.
- Public professional evidence only: explicit insufficiency, non-evaluative judgment redirection, refusal of sensitive requests/BC commitments, injection resistance. No accounts/contact/fit/personalization/analytics/Web/private fallback.
- Zero euros; no automatic processing retry, repair, failover or overage. Initial configurable limits: 1,000 characters without truncation, 20 admitted turns, 10 creations/IP/UTC day. Use temporary shared pseudonymous counters. Clarifications/new-id retries count; same-id recovery/replay/reads/rejects do not. Verify provider billing/quota facts.

## Technical Decisions

- D1 owns transcripts; portable core owns policy. Authenticate Conversation-scoped tokens before replay; hash them and never expose credentials.
- Build only reviewed `content/public/**/*.md` from a committed full SHA: stable IDs, public visibility and dated BC review metadata. Derive deterministic chunks/catalog using JCS/SHA-256; verify immutable asset before atomic singleton-and-dataset activation.
- Admission atomically freezes exact text/identity/nonempty global IDs with accounting/fenced lease; no queue. Withdrawals fail closed without membership drift. Scope FTS before ranking; retain original excerpt text/IDs/hash/title/revision.
- Classify before retrieval; clarify/refuse skip generation. History/catalog interpret, not prove facts; cap history at 3,000 tokens plus total-capacity checks. Validate blocks/citations/language before atomic result/evidence/lease release; never stream or maintain independent completion flags.
- Unknown outcomes use original-id manual recovery; recorded retryable failures use new-id question-local retry with original scope/root context. Preserve newer drafts. Initial backend/browser budgets: 30/45 seconds. No automatic processing retries.

## UX & Interaction Patterns

French UI; answers follow question/request, excerpts remain original-language. Preserve warm-paper style/fonts, mobile identity and bounded bottom composer. Show UUID/truthful storage/provider disclosure. Suggestions submit once; free entry sends nothing; “Quelques repères” starts open/manual. Draft stays editable during blocked sends; three-dot waiting.

Passage citations open grouped saved excerpts: desktop file titles/mobile distinct-file count. Nondisplacing panels/overlay sheets restore focus/reading. Separate pending/draft/view session capsule, never transcript cache; prove same-tab versus new/copied/restored visits and truthful volatile storage-denial behavior. Reload-only reads: nonoverlapping, about every 3 seconds, at most 45 seconds. “Vérifier à nouveau” reads; “Réessayer” belongs to the failed question, never composer.
