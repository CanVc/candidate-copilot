# Candidate Copilot — maquette v2

Cette archive contient la maquette avec landing page et transition vers l’interface de chat.

## Lancement

Ouvrir `index.html` dans un navigateur. Aucun serveur, paquet ou outil de compilation n’est nécessaire.

Le HTML, le CSS et le JavaScript sont regroupés dans ce fichier unique.

## Fonctionnalités simulées

- landing page responsive ;
- transition animée vers la conversation ;
- accès direct au chat depuis trois questions suggérées ;
- retour vers la landing page ;
- saisie libre et réponses de démonstration ;
- navigation compatible avec l’historique du navigateur.

La base Markdown, SQLite, le moteur de recherche et le LLM ne sont pas encore connectés.
